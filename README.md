# 복불복 제비뽑기

회식용 복불복 제비뽑기 웹 게임입니다. 설치 없이 `index.html` 파일 하나로 동작하며, 핸드폰 화면에 맞춰져 있습니다.

## 진행 방법
1. **수행자 뽑기** – 수행자 상자에서 이름을 한 명 뽑습니다.
2. **룰렛** – 복/불 룰렛을 돌려 그 사람의 복 또는 불을 정합니다.
3. **제비뽑기** – 정해진 상자에서 종이를 한 장 뽑습니다.
   - 복 상자: ☕ 커피카드 3장, 🔋 보조배터리 1장, 🖱️ 무선마우스 1장, 🍭 츄파춥스 1장
   - 불 상자: 🍻 건배사 1장, ✍️ 삼행시 2장 (주제어는 아직 안 나온 것 중 랜덤)

- 한 번 뽑힌 종이와 수행자는 다시 나오지 않습니다.
- 복 종이가 모두 소진되면 룰렛은 무조건 **불**에 멈춥니다. (불이 먼저 소진되면 무조건 복)
- 진행 상황은 브라우저에 자동 저장되어 새로고침해도 이어집니다.
- 태블릿(아이패드 등)에서는 화면 크기에 맞춰 전체가 커집니다 (최대 2배). 가로로 두면 왼쪽에 현황·기록, 오른쪽에 게임 화면이 나옵니다.

## 설정 (⚙️)
- 수행자 추가/삭제 (쉼표로 여러 명 한 번에 추가)
- 삼행시 주제어 추가/삭제
- 제비 수량 변경: 커피카드·보조배터리·무선마우스·츄파춥스·건배사·삼행시 (초기화 시 반영)
- 게임 초기화

## 핸드폰에서 열기
GitHub 저장소 Settings → Pages 에서 브랜치를 선택해 배포하면 `https://<아이디>.github.io/company_game/` 주소로 접속할 수 있습니다.

## 디자인 에셋
- `assets/`: 게임 화면에 쓰는 이미지 (로고, 룰렛 테두리·포인터·허브, 상자 3종, 제비 카드 5종, 배경, 앱 아이콘)
- `design/generated/`: AI로 만든 원본 디자인 시트
- `design/extract_assets.py`: 원본 시트에서 에셋을 잘라 `assets/`에 다시 만드는 스크립트
- `design/card_maker/`: 시트에 아직 없는 상품 카드를 임시로 만드는 도구 (기존 카드 틀 + 이모지)
- 룰렛 칸(복/불 8칸)은 결과와 정확히 맞도록 코드로 그리고, 테두리·전구·GO 버튼만 이미지를 씁니다.
