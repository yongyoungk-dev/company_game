# 복불복 제비뽑기

회식용 복불복 제비뽑기 웹 게임입니다. 설치 없이 `index.html` 파일 하나로 동작하며, 핸드폰 화면에 맞춰져 있습니다.

## 진행 방법
1. **룰렛** – 복/불 룰렛을 돌려 복 또는 불을 정합니다.
2. **제비뽑기** – 정해진 상자에서 종이를 한 장 뽑습니다.
   - 복 상자: ☕ 커피카드 3장, 🔌 무선충전기 1장, 🔋 보조배터리 1장
   - 불 상자: 🍻 건배사 1장, ✍️ 삼행시 2장 (주제어는 아직 안 나온 것 중 랜덤)
3. **수행자 뽑기** – 수행자 상자에서 이름을 한 명 뽑습니다.

- 한 번 뽑힌 종이와 수행자는 다시 나오지 않습니다.
- 복 종이가 모두 소진되면 룰렛은 무조건 **불**에 멈춥니다. (불이 먼저 소진되면 무조건 복)
- 진행 상황은 브라우저에 자동 저장되어 새로고침해도 이어집니다.

## 설정 (⚙️)
- 수행자 추가/삭제 (쉼표로 여러 명 한 번에 추가)
- 삼행시 주제어 추가/삭제
- 제비 수량 변경: 커피카드·무선충전기·보조배터리·건배사·삼행시 (초기화 시 반영)
- 게임 초기화

## 핸드폰에서 열기
GitHub 저장소 Settings → Pages 에서 브랜치를 선택해 배포하면 `https://<아이디>.github.io/company_game/` 주소로 접속할 수 있습니다.
